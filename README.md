# 🎮 Final Project - TalkBack (Chat & Dice Game)

A full-stack web application combining real-time chat and an interactive multiplayer dice game. Built with **React**, **Node.js**, **MongoDB**, and **Socket.io**.

## 🚀 Features

- ✅ User Authentication (JWT-based)
- 💬 Real-time Chat between online users
- 🎲 Turn-based Dice Game (similar to Perudo)
- 🧠 Game logic including betting, bluffing, and winning detection
- 🔄 Auto-updating game state with real-time sockets
- 🌐 Responsive UI with session handling for multi-tab play

## 🛠 Tech Stack

| Frontend | Backend | Database | Other |
|----------|---------|----------|-------|
| React    | Node.js | MongoDB  | Socket.io, Express, JWT, CSS |

## 🔧 Installation

### 1. Clone the repo
```bash
git clone https://github.com/MeravShyachi/talkback-app.git
cd talkback

### 2. Install dependencies
For the server:
cd server
npm install

For the client: Open a new terminal tab/window:
cd client
npm install

### 3. Start the app
In the server terminal:
npm start

In the client terminal:
npm start
